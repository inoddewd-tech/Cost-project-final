# Stock Management System

A Java Swing & Maven-based Stock Management System built for object-oriented programming validation, multi-entity tracking, and secure authentication.

## 🚀 Git Branch Strategy & Matrix

To keep our GitHub contributions separate and clean, **do not commit directly to `main`**. Everyone has a dedicated feature branch.

| Role / Member | Entity Focus | Assigned Feature Branch |
| :--- | :--- | :--- |
| **Team Leader** | Core Skeleton, DB Connection & Auth | `feature/auth-skeleton` |
| **Member 2** | Product CRUD Management | `feature/product` |
| **Member 3** | Supplier Details Tracking | `feature/supplier` |
| **Member 4** | Dealer Logistics | `feature/dealer` |
| **Member 5** | Employee HR Records | `feature/employee` |
| **Member 6** | Administrative System Logs | `feature/admin` |
